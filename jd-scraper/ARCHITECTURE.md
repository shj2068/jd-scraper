## 核心组件

### 1. MCP Server (reverse_engineering_mcp)

**职责**: 提供标准化的逆向工程工具接口

**核心工具**:
- `capture_traffic`: 网络流量捕获与分析
- `analyze_encryption`: 加密参数识别与算法推断
- `hook_function`: 动态 Hook 与参数监控
- `decompile_binary`: 二进制文件反编译
- `generate_fingerprint`: 设备指纹生成与伪装

### 2. Skills Framework

**TrafficSniffer Skill**:
- 自动嗅探网络请求
- 识别可疑加密参数
- 生成参数分类报告

**CryptoAnalyzer Skill**:
- 加密算法特征匹配
- 签名公式推断
- 复现代码生成

**DynamicVerifier Skill**:
- Frida 动态验证
- 参数组合测试
- 算法确认

**CodeGenerator Skill**:
- 生成可复用的采集代码
- 支持多种语言 (Python/Node.js)
- 集成到现有 jd-scraper 架构

**JDFinance Skill**:
- 京东金融 APP 专用
- 金条接口逆向
- 签名算法实现

### 3. AI Orchestrator

**职责**: 智能任务编排与调度

**工作流**:
1. 接收用户请求
2. 意图识别 (逆向工程任务)
3. 任务分解 (抓包 → 分析 → 验证 → 复现)
4. Skill 选择与调度
5. 结果聚合与报告生成

## 技术栈

### Python 核心
- `frida`: 动态插桩
- `mitmproxy`: 流量捕获
- `curl_cffi`: TLS 指纹模拟
- `httpx`: HTTP 客户端
- `pydantic`: 数据模型
- `asyncio`: 异步编排

### Node.js 服务
- `express`: MCP Server
- `playwright`: 浏览器自动化
- `frida`: 动态 Hook

### 配置管理
- `settings.yaml`: 统一配置
- `agent_config.yaml`: Agent 配置
- `jd_finance_config.yaml`: 京东金融专用配置
